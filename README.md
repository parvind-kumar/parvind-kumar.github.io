# Parvind Kumar — Author Website

Responsive static author website for `parvind-kumar.github.io`.

## Files

- `index.html` — main page, SEO metadata and structured data
- `css/style.css` — responsive editorial design
- `js/script.js` — book catalogue, filters, mobile menu and animations
- `images/` — place for real author/book images

## Before publishing

1. Replace the placeholder Instagram URL in `index.html` with the author's real Instagram profile.
2. Replace the placeholder X URL in `index.html` with the author's real X profile.
3. Replace `mailto:author@example.com` with the real author email.
4. Replace the Amazon search URLs in `js/script.js` with exact Amazon product URLs/ASINs.
5. Replace the `PK` portrait placeholder with a real author photo if desired.
6. Replace the CSS-generated book covers with real cover images when available.
